# 🚀 Туториал: Как заприватить территорию **Lands** на сервере

Этот гайд поможет тебе быстро разобраться, как **захватывать территории**, управлять ими и приглашать друзей 🏡. Всё просто — читай по шагам!

---

## 🔰 Начало игры

Чтобы **создать свою землю**, достаточно прописать:

```
/lands claim
```

👉 После этого у тебя появится своя территория с твоим ником в качестве имени.

Если хочешь сразу придумать название:

```
/lands create <название>
```

---

## 📦 Захват территории (Claim)

Ты можешь захватывать **маленькие куски** или **большие области**.

- Для быстрого захвата — команда:

  ```
  /lands claim
  ```

- Для выбора области:
  1. Введи:
     ```
     /lands selection
     ```
  2. Выбери два угла территории (щёлкни).
  3. Подтверди:
     ```
     /lands claim
     ```

Теперь земля твоя! 🎉

---

## ⚙️ Управление землёй

- Открой меню:
  ```
  /lands
  ```
- Или посмотри список команд:
  ```
  /lands help
  ```

Тут можно всё настраивать через удобное меню 📜.

---

## 🏘 Несколько земель

Если ты состоишь сразу в нескольких землях:

- Выбери, для какой земли будут выполняться команды:
  ```
  /lands edit <название_земли>
  ```
- Через **меню GUI** переключаться ещё проще (никаких команд не нужно).

---

## 👥 Доверие игрокам

### ✅ Дать доступ другу:

```
/lands trust <ник> [область]
```

Если область не указана — друг получит доступ ко всей земле.

Или через меню:

- `/lands` → меню игроков → кнопка **Trust Player**.

### ❌ Убрать доступ:

```
/lands untrust <ник> [область]
```

Или в меню: **Untrust Player**.

---

## 🔑 Права и роли игроков

1. Введи:
   ```
   /lands
   ```
2. Нажми на предмет **Roles**.
3. Настрой права для каждой роли (строить, ломать, взаимодействовать и т.д.).

---

## ⬆️ Повышение / ⬇️ Понижение игроков

1. Открой меню:
   ```
   /lands
   ```
2. Перейди в **меню игроков**.
3. Нажми на игрока:
   - **Shift + ЛКМ** — повысить 🔼
   - **Shift + ПКМ** — понизить 🔽

---

## 🎯 Итог

Теперь ты знаешь, как:

- Создать и назвать землю 🏠
- Увеличивать свои территории 📏
- Управлять меню и командами ⚡
- Добавлять/убирать друзей 👥
- Настраивать роли и повышать игроков 🔑

💡 Совет: если что-то забыл — всегда пиши:

```
/lands help
```

Удачи в освоении своих земель! 🌍✨
